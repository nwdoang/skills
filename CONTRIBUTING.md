# Contributing

## Reporting bugs

Use the bug issue template and include the affected skill, harness, observed behavior, and a reproducible context where possible.

## Suggesting improvements

Use the idea template. Start with the real problem and use case rather than a prescribed implementation.

## Pull requests

Keep each pull request focused and explain the observed problem. Avoid unrelated refactors, update documentation when behavior changes, and ensure `scripts/validate-skills.sh` passes.

## New skills

A proposal should explain the problem, why an existing skill cannot solve it, a real use case, and the expected behavior. Review [SCOPE.md](SCOPE.md), [AGENTS.md](AGENTS.md), and [.agents/skill-authoring.md](.agents/skill-authoring.md) first.
